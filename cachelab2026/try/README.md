`gemm_best.cpp` 的 case1 结构：

```
for i = 0..3, j = 0..3:            # C 的 4x4 块
    acc[4][4] = 0                  # 16 个累加寄存器
    for kk = 0..7:                 # 每次 2 个 k（2kk, 2kk+1）
        av0[0..3] = A[4i+r][2kk]       # 4 条 load（4 条 cache 行）
        av1[0..3] = A[4i+r][2kk+1]     # 4 条 load（同一批 4 条行，命中）
        for c = 0..3:
            b0 = B[2kk][4j+c]          # 1 条 load（1 条 cache 行）
            acc[r][c] += av0[r] * b0   # r=0..3
            b0 = B[2kk+1][4j+c]        # 1 条 load
            acc[r][c] += av1[r] * b0   # r=0..3
    C[4i+u][4j+v] = acc[u][v]      # 16 条 store，每个 C 元素只写一次
```

case2 同构（`i, j = 0..7`，32 个深度 → 16 轮 `kk`）；case3 同构 + 行/列/k 的越界判断。

## 评分

```
W = 0.3 × case1 + 0.3 × case2 + 0.4 × case3 = 0.3×8.35 + 0.3×9.42 + 0.4×5.72 = 7.62
性能分 = min(1, (W - 1) / (8 - 1)) × 100 = 94.55 / 100      （W = 8 为满分线）
```

官方脚本复测（`python3 test/gemm_test.py`）：case1 8.3466 / case2 9.4191 / case3 5.7216，Weighted Speedup 7.6184，94.55/100。

## 怎么复现

```bash
cp try/gemm_best.cpp gemm.cpp
make case1 && ./printTrace case1 > /tmp/t.trace && ./csim-ref -s 5 -E 1 -b 4 -t /tmp/t.trace
python3 test/gemm_test.py          # 三题一起打分（会自动编译）
```

> 注意：`csim-ref` 的输出是 `hits:X misses:Y evictions:Z`，取 misses 要用 `awk '{print $2}'`。
